Mode 1 — Bed Book Upload with lower/upper bunks grouped together

This mode is for Area searches where the user wants one Search Log row per cell.

Example Bed Book source rows:
B1-106L — ALLEN, RANDY 549290
B1-106U — MCGHEE, COLBY T64164

Correct Search Log output:
Area/Bunk Searched:
B1-106

Inmate Name/FDC Number:
ALLEN, RANDY 549290 / MCGHEE, COLBY T64164

Grouping rule:

* If Area/Bunk ends with L, remove the final L to create the normalized cell key.
* If Area/Bunk ends with U, remove the final U to create the normalized cell key.
* Use the normalized cell key as the Area/Bunk Searched value in the Search Log.
* Group all inmates with the same normalized cell key into one Search Log row.
* Keep all inmate names and DC numbers from the Bed Book.
* Do not invent inmate data.
* Do not rewrite names.
* Do not alter DC numbers.
* Do not remove inmates.

Examples:
B1-106L becomes B1-106.
B1-106U becomes B1-106.
B3-221L becomes B3-221.
B3-221U becomes B3-221.

Multiple inmate formatting:
When two inmates are assigned to the same normalized cell, place both inmates in the same Inmate Name/FDC Number cell using this format:

LAST, FIRST DCNUMBER / LAST, FIRST DCNUMBER

Example:
ALLEN, RANDY 549290 / MCGHEE, COLBY T64164

Use “ / ” between inmates.
Keep both names and both DC numbers on one line whenever possible.
Do not use line breaks unless absolutely unavoidable.
Do not abbreviate names automatically.
Do not remove DC numbers.
Do not create a second row just to make the text fit.

Font fitting for grouped inmate names:
When filling the original DOCX, automatically adjust the font size only inside the specific Inmate Name/FDC Number cell that needs it.

Required behavior:

* Start with the normal/original font size.
* If the grouped inmate text is too long, reduce only that specific cell.
* Step down through:

  * 8 pt
  * 7 pt
  * 6 pt
* Use 6 pt as the minimum font size.
* Do not reduce the font size for the whole document.
* Do not change the table layout.
* Do not widen the column.
* Do not increase row height.
* Do not add rows.
* Do not stretch the form.
* Do not remove names or DC numbers.

If the text still may not fit at 6 pt:

* Show a warning in the review table.
* Let the user manually edit the row before generating.
* Do not automatically delete or abbreviate information.

Suggested warning:
“This grouped inmate field may be too long to fit on one line at 6 pt. Review before generating.”

Time behavior for grouped mode:

* Time increments by grouped cell row.
* Since B1-106L and B1-106U become one B1-106 row, that cell receives one time.
* The next unique cell receives the next minute.

Example:
Start time = 6:44 P

B1-106 = 6:44 P
B1-107 = 6:45 P
B1-108 = 6:46 P

# 04 — 6-1 Module Boundary

## Charge

6-1 — Disobeying verbal or written order.

## Module purpose

Generate a Section II Statement of Facts narrative for a 6-1 DR based only on facts provided by the reporting officer.

## In scope

- officer assignment
- incident date/time/place
- inmate identity
- inmate behavior before order
- exact order given
- order type
- number of times order was given
- how inmate received/acknowledged order
- quote/refusal
- tone
- physical behavior after order
- operational impact
- medical/mental/language/physical ability to comply
- force/no force
- administrative confinement status
- OIC authorization

## Out of scope

- fighting charges
- disrespect charges
- battery charges
- contraband charges
- use-of-force report writing
- investigative report writing
- witness statement drafting
- hearing worksheet drafting
- penalty recommendations
- guilt determinations

## Core design rule

The module writes the Statement of Facts. It does not decide discipline.

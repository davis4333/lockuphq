# examples/6-1 — Charge 6-1 Practice DR Examples

Charge: 6-1 — Disobeying Verbal or Written Order

---

## What belongs here

### practice/

Fake training and new-hire example disciplinary reports only.

- Names, DC numbers, dates, locations, and incidents are all invented.
- No real inmate data.
- No real officer reports.
- No real case numbers.
- No real incident details.

**WARNING: Never place a real disciplinary report in this folder.**
If you are unsure whether an example is real, do not add it here. Real reports
must be fully anonymized before entering any project folder — see
`docs/STEP_4I_6-1_EXAMPLE_DR_CORPUS_PLAN.md` for the anonymization workflow.

### reviewed/

Practice examples that have been checked and approved for KB influence.

- Examples here have been read for quality, structure, and pattern value.
- Each reviewed example has a corresponding notes entry in `notes/`.
- Lessons from reviewed examples may inform KB wording, prompt rules, or test cases.
- Strong phrases may be proposed for KB updates (separate commit + tests required).

### notes/

Extracted lessons from reviewed examples.

- Strong wording patterns worth keeping.
- Weak wording patterns to avoid.
- Common missing facts observed.
- Common 6-1 fact patterns.
- Useful transition phrases.
- Bad habits that should be caught by RED/YELLOW gates.
- Possible new test cases suggested by the examples.

---

## How examples should be used

Examples influence patterns only — they are never copied word-for-word into generated reports or into the KB.

The officer remains the author of every report. The AI formats facts the officer provides. Example DRs teach the system what strong and weak reports look like, but they never become output or source text.

# 01 — Build Order

## Step 01 — Knowledge Base Foundation

Create the project structure, source register, 6-1 skeleton, global guardrails, and locked output format.

## Step 02 — Source-Backed 6-1 Knowledge Base

Fill the 6-1 module with source-backed rule details, required facts, charge elements, dismissal risks, and wording standards.

## Step 03 — Gate Engine

Build red/yellow/green validation rules for 6-1. The gate runs before Claude.

## Step 04 — Claude Contract

Define Claude input JSON, system prompt, output JSON, refusal/blocker format, and report-generation rules.

## Step 05 — Test Case Bank

Create fake green/yellow/red cases for 6-1. No real inmate or staff information.

## Step 06 — Question Flow

Build plain-English questions mapped directly to the locked six-paragraph format.

## Step 07 — Report Quality Tuning

Run test cases through Claude and score output against the locked format.

## Step 08 — UI / Replit / LOCKUPHQ.com

Only after the engine is strong, build the polished interface.

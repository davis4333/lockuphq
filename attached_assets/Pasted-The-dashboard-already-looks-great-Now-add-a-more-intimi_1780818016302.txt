The dashboard already looks great. Now add a more intimidating classified restricted-system atmosphere.

Do not change the main layout, background, card positions, right-side panels, header structure, or functionality. This is an atmosphere and micro-interaction polish pass only.

The goal is to make the dashboard feel like officers are opening a restricted internal command system they probably should not be casually clicking around in — secure, classified, serious, and slightly unsettling — while still clearly being a training/sandbox tool.

Overall vibe

Make it feel like:

restricted government command system
classified terminal
blacksite-style secure dashboard
internal operations console
high-security training environment

Do not make it look like a horror game, hacker website, or cheesy movie prop.

Use red sparingly. The main theme should remain blue/green FDOC command center, with red/amber used only for warnings, denied access, and classification bars.

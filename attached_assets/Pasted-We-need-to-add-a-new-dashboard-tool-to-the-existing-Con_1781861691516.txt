3. Dorm & Cell #

Because the B is already printed on the form.

* Do not remove the bunk suffix unless the user specifically chooses a different option later.
* Do not overwrite the existing printed B on the form.

Examples:
B1-106L → 1-106L
B1-106U → 1-106U
B3-221L → 3-221L

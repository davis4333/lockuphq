# examples/6-1/notes

This folder contains extracted lessons from fake practice/new-hire example DRs.

## What belongs here

- Pattern analysis documents derived from reviewed practice examples
- Fact-pattern tag summaries
- Proposed test case candidates
- Phrase pattern notes
- Weak-spot observations
- UI helper text suggestions

## What does not belong here

- Real disciplinary reports
- Real inmate names, DC numbers, or case numbers
- Raw copies of any DR example (raw text belongs in `practice/` before review)

## How notes are used

Notes influence patterns only — they are never copied word-for-word into generated reports, KB files, or prompt rules. Lessons from notes may propose KB changes or new test cases, but those changes go through their own review and test cycle before being applied.

# prototypes/

Static UI mocks for LOCKUPHQ DR Writer. Layout review only.

## charge-6-1-static-form.html

Step 5B static mock for the Charge 6-1 DR Writer form.

**How to open:** Double-click `charge-6-1-static-form.html` in Finder/Explorer, or run:

```
npm run mock:6-1:ui
```

Then open the file path shown in a browser.

**What this is:**
- Visual layout of all 14 intake sections
- Officer-friendly two-column layout: form on left, review panel on right
- RED/YELLOW/GREEN status explanation cards
- Sample output narrative placeholder
- All buttons visible — Generate Narrative is intentionally disabled

**What this is NOT:**
- Not connected to the backend
- Not connected to Claude
- Does not call any API
- Does not store data
- Does not generate real reports

**Do not enter real inmate names, DC numbers, or officer information into this prototype.**
